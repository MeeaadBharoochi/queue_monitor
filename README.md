# Queue Monitor

A Chrome DevTools snippet that automatically refreshes a queue page at regular intervals to help monitor for new work items.

## Current Features

- Automatic page refresh
- Configurable refresh interval
- Runs directly from Chrome DevTools Snippets
- Lightweight JavaScript implementation
- Reduces the need for manual page refreshes

## Project Status

🚧 Work in Progress

The current version focuses on automated page refreshing. Future enhancements will build on this foundation to provide queue monitoring and alerting capabilities.

## Planned Features

- Queue item detection
- Audible alerts when work is available
- Desktop notifications
- Start/Stop controls
- Refresh statistics
- Custom alert settings
- Persistent configuration storage

## Technologies

- JavaScript
- Chrome DevTools
- Git

## Usage

1. Open Chrome DevTools.
2. Navigate to **Sources → Snippets**.
3. Run the `queue_monitor.js` snippet.
4. The page will automatically refresh based on the configured interval.
